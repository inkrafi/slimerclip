# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom — "lampu studio"
- **Notes:** Studio podcast diterangi lampu gel: latar indigo-ungu (`--color-bay` #1d1a45) dengan pendaran magenta/toska/biru,
  panel kaca berbatas 1px, pink gel `#ff5fa2` untuk aksi utama, toska `#3dd6c6` warna kedua, warna label klip per sudut konten.
  Judul Plus Jakarta Sans, teks UI Onest, Syne hanya untuk wordmark. Tabel & laporan data mengikuti kejelasan ala Stripe
  (angka tabular, garis tipis, hierarki tegas). Token sumber: `frontend/src/app/globals.css`.

## Banned anti-aesthetics

- Glassmorphism di luar kelas `.glass` yang ada; `.glass` wajib border 1px + teks terbaca. Dilarang blur baru, kaca bertumpuk, kaca tanpa batas
- Badge pil pastel melayang untuk metadata biasa (pil hanya untuk status)
- Gradien dekoratif sembarangan & border neon menyala (pendaran latar "lampu studio" tetap boleh)
- Gradien pelangi pada tombol aksi biasa
- Ilustrasi kartun di tampilan kosong
- Scrollbar bertumpuk; ikon berlebihan di dalam input
- Aksen kuning sebagai warna aksi utama (aksi utama = pink gel)

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** teks normal ≥ 4,5:1, teks besar & border/ikon penting ≥ 3:1 terhadap latar indigo; `ink-faint` hanya untuk teks non-esensial
- **Touch / focus:** target sentuh ≥ 44×44 px; cincin fokus 2px pink gel (`outline` yang sudah ada), selalu terlihat saat navigasi keyboard

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Sapa dengan "kamu" (EN: "you"), jelaskan alasan singkat, selalu beri langkah berikutnya; tidak menyalahkan pengguna.
  Halaman publik dua bahasa (id/en, lihat `frontend/src/lib/i18n.ts`); ruang kerja & editor bahasa Indonesia.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (^1.16.0)
- **Notes:** Satu pustaka untuk seluruh UI; tidak dicampur set lain; tanpa emoji sebagai ikon.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
